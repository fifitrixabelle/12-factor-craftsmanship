This synchronous startup-only library reads a small UTF-8 token file selected by trusted application configuration. The deployment mounts a private secret file, controls permissions, and supplies the absolute path. Whitespace is not part of the token. Missing/unreadable files and empty tokens must fail startup; the consumer intentionally propagates those errors. Rotation is applied by restarting the consumer. The library does not accept HTTP input, log token values, or own a server or worker process. The consumer configures the Client and its network policy. Review against this contract, without speculative scope expansion.
